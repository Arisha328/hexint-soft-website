# Project Screenshots

Drop a screenshot for each project here, named to match its `slug` in
`src/data/projects.js`. Supported: .jpg or .png (update the `image` path in
projects.js if you use .png).

Expected filenames:

- shopverse-marketplace.jpg
- smart-study-planner.jpg
- loan-default-prediction-system.jpg
- ai-finance-tracker.jpg
- responsive-ecommerce-website.jpg
- flight-management-system.jpg
- university-management-system.jpg
- skincare-mobile-app-ui.jpg

Recommended size: 1200x900px (4:3), under 300KB each (export as JPG at
~80% quality, or use an online compressor like squoosh.app before adding).

Until a file exists, that project's card automatically falls back to the
branded maroon gradient placeholder — nothing breaks either way.
